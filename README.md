# go-dupfind

按内容（SHA-256）查找重复文件。标准库实现，零依赖。先按文件大小快速分组，再对大小相同的文件做哈希，避免无谓的 IO。

```powershell
go run . C:\Users\ASUS\Pictures -min 1024
go run . . -del          # 交互式删除重复项（每组保留第一个，标 *）
```

参数：

- 位置参数：要扫描的目录（可多个，默认当前目录）
- `-min` 只比较大于等于该字节数的文件（默认 1）
- `-del` 交互式删除重复项，每组保留第一个（标 `*`），其余逐个确认

```powershell

```
