# go-dupfind

又是个懒人小工具——把平时手敲最烦的活儿自动化掉。

按内容（SHA-256）找出重复文件。先用文件大小快速分组，大小相同的才做哈希，避免无谓的磁盘读取。

```powershell
go run . C:\Users\ASUS\Pictures -min 1024
go run . . -del
```

不传目录时扫当前目录。`-min` 只比较不低于该字节数的文件；`-del` 会交互式删除重复项，每组保留第一个（标 `*`），其余逐个确认。

用法：

- 位置参数：要扫描的目录，可传多个，默认当前目录
- `-min` 只比较大于等于该字节数的文件（默认 1）
- `-del` 交互式删除重复项，每组保留第一个，其余逐个确认
